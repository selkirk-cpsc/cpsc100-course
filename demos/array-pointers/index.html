Array Pointers: same boxes, different spellings

The array and pointer examples from the lecture slides, run one line at a time. An array is a row of boxes side by side, each at its own address. A pointer is a separate box that holds one of those addresses, drawn as an arrow. Keys: →/Space next, ← back.

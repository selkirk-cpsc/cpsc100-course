Arrays to Functions: the address goes in, not the array

The array examples from the lecture slides, run one line at a time. When main() passes an array to a function, the function gets one box holding the address of the first element, drawn as an arrow. The array itself never moves. Keys: →/Space next, ← back.

A parameter written int arr[] is really int *arr: one box holding an address. That's why changes to arr[i] land in main's array, and why sizeof(arr) only measures the pointer.

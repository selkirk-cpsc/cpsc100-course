Read-Only Strings: which letters can a function change?

The string examples from the lecture slides, run one line at a time. A string literal's letters live in read-only memory; a char array gets its own copy that the program may change. A function only ever gets an address, so what it may do depends on where that address leads. Keys: →/Space next, ← back.

In a parameter list, char s[] and char *s mean the same thing: one box holding an address. A function that changes a string needs a character array; a literal is only safe for a function that reads it, like one taking const char *.

Scope Explorer: Where Can This Variable Be Seen?

The examples from the lecture slides. Run each program one line at a time and watch its variables appear and disappear, and click any underlined variable name: a declaration shades every line where that variable can be used, and a use shows which declaration it belongs to, or why it isn't allowed there. Keys: →/Space next, ← back.

Rule of thumb: a variable can be used from the line where it's declared down to the } that closes the braces it was declared in. A variable declared outside every function (a global) can be used from its declaration to the end of the file.

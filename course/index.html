CPSC 100 Course info

Course Info

An introductory programming course in C with emphasis on basic programming constructs, algorithms, program design, and good programming practices. You'll develop and test C programs that use control flow, arrays and strings, functions, pointers and dynamic memory, and structs.

Classes

What happens
Lecture (Tuesdays) New material. The notes for each lecture go up after it's taught.
Tutorial (Thursdays) Hands-on programs on that week's topic, submitted on Moodle.

How the course is graded

Component Weight
Tutorials (graded on completion) 5%
Assignments (one per week; the lowest is dropped) 15%
Midterm 1 (Week 7) 25%
Midterm 2 (Week 11) 25%
Capstone project (Week 13) 5%
Final exam 25%

The course outline on Moodle has the full details, including the late policy.

Textbook

C Programming: A Modern Approach, 2nd edition, by K. N. King (suggested). The lecture notes on this site cover everything you need for the course.

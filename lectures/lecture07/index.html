Week-by-Week Recap

Week 1: Programs and Flow Diagrams

  • Every program: Input →\to Process →\to Output

  • Compile-run cycle: edit source →\to compile →\to run →\to (fix errors, repeat)

  • Four basic flow-diagram pieces: oval (start/stop), rectangle (process), parallelogram (I/O), arrow

Week 2: Variables and Basic I/O

  • A variable is a named box in memory: a name, a size (from its type), and a stored value

  • printf/scanf conversion characters must match the variable’s type: %d, %f, %c, %s

  • Strings (first look): char name[50]; – a fixed-size array of characters

  • & rule: scanf needs the address of a numeric/char variable, but not of a char array

int  age;
char name[50];
scanf("%d", &age);   // & for numeric types
scanf("%s", name);    // no & for a char array

Week 3: Operators and Expressions

  • Arithmetic operators: + - * / %

  • Integer division truncates – 7 / 2 is 3, not 3.5

  • Precedence and casting control how mixed expressions evaluate

  • #define name a value once instead of repeating a magic number

  • Multiple I/O/process blocks can chain in one straight-line sequence

int a = 7, b = 2;
printf("%d\n", a / b);          // 3
printf("%.1f\n", (float)a / b); // 3.5

Week 4: Conditionals

  • The diamond shape: decision points

  • if / else if / else

  • switch/case: multi-way branch on one int/char value – needs break

  • Relational (< > <= >= == !=) and logical (&& || !) operators

  • = assigns; == compares

Week 5: Loops

  • The loop-back arrow: sends control back to a decision diamond

  • Three templates: while (test first), do..while (body first), for (init; test; update)

  • Loop-control patterns: counter, sentinel, accumulator

  • Nested loops: inner dashed box completely inside outer dashed box; inner loop finishes fully for each outer iteration

  • Off-by-one: < vs <= in the loop bound

// 5 iterations
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}

Week 5: The Three Loop Templates

while


Test first: the body may run zero times.

do..while


Body first: it runs at least once.

for


Init, test, body, update, then loop back.

Practice Problems

Problem 1: Integer Division

What does this print?

int total = 17, count = 5;
float average = total / count;
printf("%.2f\n", average);

Solution 1: Integer Division

int total = 17, count = 5;
float average = total / count;
printf("%.2f\n", average);

Prints 3.00, not 3.40. total / count is integer division – it computes 3 before the result is ever stored in a float. Fix: cast at least one operand, (float)total / count.

Problem 2: = vs. ==

What is wrong with this code?

int age = 20;
if (age = 18) {
    printf("You just turned 18!\n");
}

Solution 2: = vs. ==

int age = 20;
// BUG: assignment, not comparison
if (age = 18) {
    printf("You just turned 18!\n");
}

age = 18 assigns 18 to age and evaluates to 18 (nonzero →\to true) – the message always prints, and age is overwritten. Fix: if (age == 18).

Problem 3: Off-By-One

How many times does "Lap" print, and is that correct for “run 4 laps”?

for (int lap = 1; lap < 4; lap++) {
    printf("Lap %d\n", lap);
}

Solution 3: Off-By-One

// BUG: stops one short
for (int lap = 1; lap < 4; lap++) {
    printf("Lap %d\n", lap);
}

Prints 3 laps (1, 2, 3), not 4 – lap < 4 stops before lap reaches 4. Fix: lap <= 4.

Problem 5: Missing break

What prints if day is 2?

switch (day) {
    case 1: printf("Mon\n");
    case 2: printf("Tue\n");
    case 3: printf("Wed\n"); break;
    default: printf("Invalid\n");
}

Solution 5: Missing break

switch (day) {
    case 1: printf("Mon\n");
    case 2: printf("Tue\n");   // no break!
    case 3: printf("Wed\n"); break;
    default: printf("Invalid\n");
}

Prints Tue and Wed – once case 2 matches, execution keeps running until it hits a break or the end of the switch. Fix: add break; after each case’s statements.

Problem 6: Conversion Character Mismatch

What does this print?

float price = 19.99;
printf("Price: %d\n", price);

Solution 6: Conversion Character Mismatch

float price = 19.99;
// BUG: %d expects an int
printf("Price: %d\n", price);

Undefined behavior – %d reads the bytes of price as if they were an int, producing garbage output (not 19 or 20). Fix: match the conversion character to the type, printf("Price: %.2f\n", price);.

Common Mistakes

Mistake: Conversion Character Mismatch

Buggy

float gpa = 3.85;
printf("%d\n", gpa);

Fixed

float gpa = 3.85;
printf("%.2f\n", gpa);

Rule: the conversion character must match the variable’s type – %d for int, %f/%.Nf for float/double.
Type: logic error (it compiles, with a warning, but prints garbage).

Mistake: = Instead of ==

Buggy

if (count = 0) {
    printf("Empty\n");
}

Fixed

if (count == 0) {
    printf("Empty\n");
}

Rule: = assigns a value; == compares two values. A condition should almost always use ==.
Type: logic error (it compiles, but the condition is wrong).

Mistake: Forgetting & in scanf

Buggy

int age;
scanf("%d", age);

Fixed

int age;
scanf("%d", &age);

Rule: scanf needs the address of a numeric or char variable to store into – & provides that address.
Type: runtime error (it compiles, with a warning, then crashes).

Mistake: Missing Braces Around a Loop Body

Buggy

int i = 0;
while (i < 3)
    printf("%d\n", i);
    i++;

Fixed

int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}

Rule: without braces, only the first statement is the loop body. i++ never runs inside the loop, so i stays 0 and it prints 0 forever. Indenting doesn’t change this.
Type: logic error (it compiles and runs, but never stops).

Mistake: Missing break in switch

Buggy

switch (grade) {
  case 'A':
    printf("Great\n");
  case 'B':
    printf("Good\n");
}

Fixed

switch (grade) {
  case 'A':
    printf("Great\n");
    break;
  case 'B':
    printf("Good\n");
    break;
}

Rule: without break, execution falls through into the next case regardless of its label.
Type: logic error (it compiles, but runs the wrong cases).

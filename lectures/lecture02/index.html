Memory

Memory is Physical Hardware

Before we look at variables and data types, it helps to understand where data actually lives.

Memory is a real, physical piece of hardware inside the computer; not just an abstract idea.

RAM vs. Persistent Storage

There are two different kinds of storage hardware:

  • RAM (Random Access Memory); temporary storage

    • holds a program’s variables while it is running

    • very fast to read and write

    • erased when the program ends or the computer loses power

Photo: PantheraLeo1359531, CC BY 4.0, via Wikimedia Commons

Every variable you declare this term lives in RAM.

  • Disk or Flash; persistent storage

    • holds your source files, compiled programs, and saved data

    • much slower than RAM

    • survives after the program ends and the computer is turned off

Photo: Zzubnik, public domain, via Wikimedia Commons

From Hardware to a Mental Model

RAM is a real chip with billions of physical storage cells; but working at that level is far too low-level for everyday programming.

Instead we use a simpler mental model:

  • Picture RAM as one very long row of small storage boxes

  • Each box has a numeric address; for now we let the compiler manage addresses for us, but we will work with them directly later when we cover pointers

  • Instead, we give a box a name we choose; that is a variable

A variable is a named box in memory that holds a value.

Data Types

Why a Box Needs a Type

Knowing where a box is isn’t enough; the computer also needs to know how to interpret the bits inside it.

  • Inside memory, everything is just patterns of 0s and 1s

  • The exact same bit pattern means something completely different depending on how it is read

This is why every variable in C must have a data type; the type tells the compiler how many bits to use and how to interpret them.

Kinds of Data

C programs work with data made up of numbers and characters.

There are many data types in C, but these are the fundamental ones:

  • Characters (char )

  • Integers (int , short )

  • Floating-point numbers (float , double )

  • A modifier that changes how integers are interpreted (unsigned )

Characters

A C character is any single character your computer can represent.

There are 256 characters on the ASCII table. For example, these are all characters:

  • A

  • a

  • 4

  • %

  • Q

  • !

  • +

  • =

  • ]

char values must be enclosed in single quotes (e.g., 'A').

Careful: 4 vs. '4'

Because a char is stored as a number, 4 and '4' are not the same thing:

  • 4 is the number four (an int )

  • '4' is the character four; C stores it as its ASCII code, 52 (look it up in the table)

  • So '4' + 1 is 53 (the character '5'), not 5

Numbers

There are different ways to express numbers in a computer.

integers represent whole numbers (int ):

  • 10

  • 54

  • 0

  • −121-121

  • −68-68

  • 752

floating-point numbers are numbers with decimal points (float ):

  • 547.43

  • 0.0

  • 0.44384

  • 9.1923

  • −168.47-168.47

  • .22

The choice of integer or floating-point type depends on the data:

  • type of data (whole number vs. decimal)

  • size of numbers expected

  • amount of memory you’re willing to spend

Storing floats often takes more memory than storing integers.

More Fundamental Types

Beyond char , int , and float , C gives you a few more choices:

  • short ; a smaller integer, for when values stay small

  • double ; double-precision floating-point; larger range and more decimal precision than float

  • unsigned ; a modifier that tells the compiler “this integer can never be negative,” which doubles the largest positive value it can hold

  • unsigned int, unsigned short; common combinations

  • Plain int and short are signed by default

Data Types: Sizes

Name Bits Description

Exact sizes are not guaranteed by the C standard; they depend on the compiler and machine.

The sizeof Operator

sizeof answers: how many bytes does this type take up on my machine?

printf("%lu\n", sizeof(int));
printf("%lu\n", sizeof(double));
Sample run
4
8

  • sizeof accepts a type name or a variable name

  • Returns a result in bytes

  • Use %lu to print it; %lu (long unsigned) is a conversion character, a placeholder that tells printf what type to expect; we will cover these in detail shortly

Don’t memorize “int is always 4 bytes”; ask the compiler with sizeof. The C standard only guarantees short ≤\leq int ≤\leq long in size.

Variables

Variables: Reserving a Named Box

In C, every variable must be declared before it is used.

A declaration does three things:

  • gives a memory location a name

  • reserves the right number of bytes for the type

  • tells the compiler how to treat the data stored there

int score = 42

Naming Variables

Variable names must follow these rules:

  • must start with a letter

  • can contain letters, digits, and underscores _

  • no special characters (*, ^, etc.) except underscores

  • case sensitive: count ≠\neq Count

  • cannot be a C reserved word:

auto break case char const continue
default do double else enum extern
float for goto if int long
register return short signed sizeof static
struct switch typedef union unsigned void
volatile while

Declaring and Initializing Variables

General form: type variableName = value;

char  answer      = 'B';
short smallCount  = 100;
int   quantity    = 14;
float price       = 7.95;
double pi         = 3.14159265;
unsigned int score = 98;

  • Declaring and initializing in one line is the preferred style; it avoids ever reading an uninitialized box

  • You can also declare first and assign later, but don’t read the variable until you have put a value in it; if you do, you get whatever random bits happened to be sitting in that memory box, called garbage values: the program compiles and runs, but the output is unpredictable

Output with printf

Printing Variables: Conversion Characters

printf uses conversion characters as placeholders; each one matches a specific data type:

Conversion char Type Example value printed
%d int , short 42
%f float , double 3.141593
%c char A
%s string (char array) hello
%lu size_t (from sizeof) 4

The conversion character must match the type of the variable you pass; mixing them gives undefined behavior.

Conversion Characters: Example

#include <stdio.h>
int main()
{
  char  grade    = 'A';
  int   score    = 95;
  float average  = 91.333333;

  printf("Grade: %c\n",   grade);
  printf("Score: %d\n",   score);
  printf("Average: %f\n", average);
  return 0;
}

Output:

Grade: A
Score: 95
Average: 91.333336

Controlling Decimal Precision

By default %f prints six decimal places. You can control this with %.Nf where N is the number of places:

float average = 91.333333;
printf("%f\n",   average);   // default: 6 places
printf("%.2f\n", average);   // 2 decimal places
printf("%.0f\n", average);   // rounded to whole number

Output:

91.333336
91.33
91

%.2f is the standard choice for currency and most user-facing output in this course.

Strings: A First Look

Strings: Text in C

So far we’ve printed string literals; text in double quotes hardcoded directly in printf:

printf("Hello, world!\n");

But what if we want a variable that holds text?

In C, a string is stored as a fixed-size array of char values:

char name[50];

  • name is an array that can hold up to 50 characters of text

  • The 50 must be large enough for the longest text you expect

  • Use %s as the conversion character to print it

Strings: Initializing and Printing

You can initialize a char array with a string literal:

char name[50] = "Alice";
printf("Hello, %s!\n", name);

Output:

Hello, Alice!

  • %s works like %d or %f; it is a placeholder for the string variable

  • The internal mechanics of how C stores strings will be covered in a later lecture; for now, just use the pattern above

Watch Out: Single Quotes vs. Double Quotes

char values and strings look similar but are not interchangeable:

char grade  = 'A';    // single quotes -> a char
char name[50] = "A";  // double quotes -> a string

  • 'A' is a single char value

  • "A" is a string; an array holding 'A' and a hidden terminating character

  • Mixing them up (e.g. char grade = "A";) will not compile cleanly, and using the wrong conversion character (%c vs. %s) prints garbage or crashes your program

Input with scanf

scanf: Reading from the Keyboard

printf sends output to the screen. scanf reads input from the keyboard.

General form:

scanf(conversionCharacter, &myVariable);

  • The format string uses the same conversion characters as printf: %d, %f, %c

  • For numeric and character variables, you must write & in front of the variable name

  • & gives scanf the address of the variable so it can store the value directly into that memory box

  • Think of it as the rule: “scanf needs the address, not the value”; the deeper reason (pointers) comes in a later week

Reading Different Types

The conversion character and & rule apply to each type:

int    age;
float  gpa;
char   grade;

scanf("%d", &age);    // read an integer
scanf("%f", &gpa);    // read a float
scanf("%c", &grade);  // read a single character

For a string, the rule is different; no &:

char name[50];
scanf("%s", name);    // no & for a char array

The array name name is already an address; that’s why & is not needed here. Again, the details come in a later week; for now, just learn the rule.

A Complete Input/Output Example

#include <stdio.h>
int main()
{
  char name[50];
  float gpa;

  printf("Enter your name: ");
  scanf("%s", name);

  printf("Enter your GPA: ");
  scanf("%f", &gpa);

  printf("Name: %s  GPA: %.2f\n", name, gpa);
  return 0;
}
Sample run
Enter your name: Alice
Enter your GPA: 3.7
Name: Alice  GPA: 3.70

Notice: %s/name has no &; %f/gpa does.

Flow Diagrams

Flow Diagrams: Declaring & Assigning are Process Steps

Recall the shapes from last week:

  • Oval; Start or Stop

  • Rectangle; a process or computation step

  • Parallelogram; input or output (printf, scanf)

Declaring a variable and assigning it a value are both process steps; they get their own rectangle.

No new shape this week; we’re reinforcing the rectangle in a new role.

Unit Conversion: Plan Before You Code

Notice the pattern:

  • Declare; a process rectangle

  • Input; a parallelogram (scanf)

  • Process; compute; another rectangle

  • Output; a parallelogram (printf)

Arithmetic Operators

Arithmetic Operators

C provides five arithmetic operators that work just like math:

Operator Meaning Example
+ Addition a + b
- Subtraction a - b
* Multiplication a * b
/ Division a / b
% Modulus (remainder) a % b

Integer Division Truncates

When both operands are integers, / performs integer division; the decimal part is discarded, not rounded.

int a = 7, b = 2;
printf("%d\n", a / b);   // prints 3, not 3.5

The modulus operator gives you the remainder left over from integer division:

printf("%d\n", a % b);   // prints 1

Note: % only works on integer types. Using it on float or double is a compile error.

Integer vs. Floating-Point Division

float a = 19.0, b = 5.0, floatAnswer;
int   x = 19,   y = 5,   intAnswer;

floatAnswer = a / b;
printf("%.1f / %.1f = %.1f\n", a, b, floatAnswer);

→\rightarrow 19.0 / 5.0 = 3.8

floatAnswer = x / y;
printf("%d / %d = %.1f\n", x, y, floatAnswer);

→\rightarrow 19 / 5 = 3.0 Integer division happened first →\rightarrow result is 3, not 3.8

intAnswer = x % y;
printf("%d %% %d = %d\n", x, y, intAnswer);

→\rightarrow 19 % 5 = 4

Operator Precedence

C evaluates operators according to a fixed precedence (which operator goes first) and associativity (which direction to resolve ties).

This is similar to BEDMAS/PEMDAS from math, but defined precisely by the language.

Level Operator(s) Associativity
1 () parentheses Left → Right
2 - (unary), ++, --, ! Right → Left
3 *, /, % Left → Right
4 +, - Left → Right
5 <, <=, >, >= Left → Right
6 ==, != Left → Right
7 && Left → Right
8 || Left → Right
9 =, +=, -=, *=, /=, %= Right → Left

Tracing an Expression

Evaluate step by step:

ans = 5 + 2 * 4 / 2 % 3 + 10 - 3;

=5+2*4/2%3+10−3=5+8/2%3+10−3=5+4%3+10−3=5+1+10−3=6+10−3=16−3=13\begin{aligned} &= 5 ~+~ \boxed{2 ~*~ 4} ~/~ 2 ~\%~ 3 ~+~ 10 ~-~ 3\\ &= 5 ~+~ \boxed{8 ~/~ 2} ~\%~ 3 ~+~ 10 ~-~ 3\\ &= 5 ~+~ \boxed{4 ~\%~ 3} ~+~ 10 ~-~ 3\\ &= \boxed{5 ~+~ 1} ~+~ 10 ~-~ 3\\ &= \boxed{6 ~+~ 10} ~-~ 3\\ &= \boxed{16 ~-~ 3}\\ &= 13 \end{aligned}

Level 3 (*, /, %) evaluated left-to-right first, then level 4 (+, -).

Using Parentheses

Parentheses override the default precedence; always evaluate first.

ans = (5 + 2) * 3;   // 21, not 11

A classic mistake: computing an average of four variables:

avg = i + j + k + l / 4;   // WRONG: only l is divided
avg = (i + j + k + l) / 4; // correct

Rule of thumb: when in doubt, add parentheses; they make intent explicit and cost nothing.

Constants

Magic Numbers Are a Bad Habit

What does this code do?

area = 3.14159 * r * r;
celsius = (temp - 32) * 5 / 9;

You can probably guess; but imagine reading someone else’s code full of unexplained numbers like 86400, 1.852, or 6371.

Named constants give those values a readable label; and make sure the same value is used consistently everywhere.

#define →\rightarrow Preprocessor Constants

#define is a preprocessor directive: before compiling, the preprocessor replaces every occurrence of the name with the value.

#define PI        3.14159
#define FREEZE_F  32
#define CM_PER_IN 2.54

The preprocessor performs a text substitution; it is not a variable:

area = PI * r * r; // becomes: area = 3.14159 * r * r;

PI itself has no type; it’s just text, swapped in before the compiler ever runs. The substituted literal does: an unsuffixed number like 3.14159 is a double by default (not float ), same as if you’d typed it directly.

Convention: use ALL_CAPS for #define names to distinguish them from variables.

Note: no = sign, no semicolon; it is not a statement.

const →\rightarrow Typed Constants

const declares a variable whose value cannot be changed after initialization.

const float PI    = 3.14159f;
const int   DAYS  = 365;

Unlike #define, a const variable:

  • has a type →\rightarrow the compiler checks it

  • is a real variable in memory, with its own address; a #define leaves nothing behind; it vanishes once the preprocessor substitutes it

#define for More Than Numbers

#define substitutes any text, not just numbers:

#define MAX_NAME   50
#define GREETING   "Hello"

Using MAX_NAME as a string size keeps things consistent:

char name[MAX_NAME];
scanf(" %49s", name);   // at most MAX_NAME-1 characters
printf("%s, %s!\n", GREETING, name);

If you ever need to change the max, you change it in one place →\rightarrow the #define line; and every use in the program updates automatically.

Type Casting

Type Casting

Type casting converts a value from one data type to another.

  • Implicit casting (type promotion); done automatically by the compiler when mixing types; the smaller type is promoted to the larger one.

  • Explicit casting; done by the programmer using a cast operator: (type) expression.

Casting is most important when you need floating-point division but your operands are integers.

Implicit Casting

int   a = 5;
float b = 2.0;
float result = a / b;   // a is promoted to float automatically
printf("result = %.1f\n", result);

Output: result = 2.5

The variable a is still an int; it is temporarily promoted to float only for this calculation.

Explicit Casting →\rightarrow Be Precise

int m = 7, n = 2;
float result1 = (float)(m / n);   // cast AFTER division
float result2 = (float)m / n;     // cast BEFORE division
printf("result1 = %.1f\n", result1);
printf("result2 = %.1f\n", result2);

Output:

result1 = 3.0
result2 = 3.5

result1: integer division 7/2=3 happens first, then 3 is cast to 3.0.

result2: m is cast to float first, so n is promoted automatically and floating-point division 7.0/2=3.5 is used.

Postfix, Prefix, and Compound Assignment

Increment and Decrement Operators

Two shorthand operators exist for adding or subtracting 1:

Operator Name Equivalent
count++ Postfix increment count = count + 1
count-- Postfix decrement count = count - 1
++count Prefix increment count = count + 1
--count Prefix decrement count = count - 1

Used as a statement on its own, prefix and postfix behave identically.
The difference only matters when the expression’s value is used.

Postfix vs. Prefix Inside an Expression

Postfix: use then increment

int i = 3, n;
n = i++ * 2;
// n = 3 * 2 = 6
// i is now 4

Prefix: increment then use

int i = 3, n;
n = ++i * 2;
// i becomes 4 first
// n = 4 * 2 = 8

Tip: avoid mixing ++/-- with other operators in the same expression; it makes intent hard to see. Use them as standalone statements.

Compound Assignment Operators

Rather than writing x = x + 5; you can write x += 5;

Operator Example Equivalent
+= count += 1; count = count + 1;
-= total -= fee; total = total - fee;
*= price *= 1.1; price = price * 1.1;
/= val /= 2; val = val / 2;
%= day %= 7; day = day % 7;

The C Standard Library

The C Standard Library

C is a small language; most of its power comes from a collection of pre-written functions called the C Standard Library.

These are pre-written, tested tools you link into your program rather than write yourself. Each library is packaged as a header file you include at the top of your program:

  • #include <stdio.h>; already know this: printf, scanf

  • #include <math.h>; mathematical functions

  • #include <ctype.h>; character classification and conversion

This week’s focus: the concept; the include-call-link pattern, shown once with sqrt(). Touring what’s inside <math.h> and <ctype.h> is Tutorial 3’s guided segment.

The Pattern: Include, Call, Link

One worked example; sqrt() from <math.h>:

#include <stdio.h>
#include <math.h>   // 1. INCLUDE the header

int main() {
    double x = 2.0;
    double root = sqrt(x);   // 2. CALL the function
    printf("sqrt(%.1f) = %.6f\n", x, root);
    return 0;
}
$ gcc prog.c -lm     # 3. LINK the math library
$ ./a.out
sqrt(2.0) = 1.414214

You did not write sqrt; someone already wrote, tested, and optimized it. The same three-step pattern works for every standard-library function you will ever use.

Flow Diagrams

Chaining Flow Diagram Blocks

So far our programs have had one Input →\rightarrow one Process →\rightarrow one Output.

Real programs often compute multiple outputs from one input, or perform multiple processing steps before producing output.

No new shapes this week. You already have everything you need:

  • Oval; Start / Stop

  • Parallelogram; Input / Output

  • Rectangle; Process

  • Arrows; flow of control

Just chain the blocks: place multiple Process/Output groups in sequence, or let one Input feed several Process++Output pairs.

The Problem: Circle Calculator

Suppose we want a program that reads a circle’s radius and reports both its circumference and its area:

circumference=2πrarea=πr2\begin{aligned} \text{circumference} &= 2 \pi r \\ \text{area} &= \pi r^2 \end{aligned}

One Input, but two separate calculations, each with its own Output.

Before writing any code, let’s draw the flow diagram; chaining two Process/Output pairs after a single Input.

Pattern 1: One Input, Multiple Process/Output Pairs

A program that reads a radius and computes both circumference and area:

Circle Calculator →\rightarrow Full Program

#include <stdio.h>
#define PI 3.14159265

int main() {
    double radius, circumference, area;

    printf("Enter radius: ");
    scanf(" %lf", &radius);

    /* Process block 1 */
    circumference = 2.0 * PI * radius;
    printf("Circumference: %.4f\n", circumference);

    /* Process block 2 */
    area = PI * radius * radius;
    printf("Area: %.4f\n", area);
    return 0;
}
Sample run
Enter radius: 2
Circumference: 12.5664
Area: 12.5664

One Input, two Process/Output pairs; just as the diagram shows.

Pattern 2: Sequential Input/Process/Output Groups

The other chaining pattern: instead of one Input feeding multiple Process/Output pairs, run complete Input→\toProcess→\toOutput groups one after another; each with its own input.

Example: convert a Fahrenheit temperature, then use it to compute a heat index; a "feels like" comfort rating that combines temperature and humidity. Related calculations, but each is its own complete group:

celsius=(fahrenheit−32)×5/9heatIndex=0.5×(fahrenheit+61+(fahrenheit−68)×1.2=0.5×(+humidity×0.094)\begin{aligned} \text{celsius} &= (\text{fahrenheit} - 32) \times 5 / 9 \\ \text{heatIndex} &= 0.5 \times \big(\text{fahrenheit} + 61 + (\text{fahrenheit}-68)\times 1.2 \\ &\phantom{{}= 0.5 \times \big(} + \text{humidity} \times 0.094\big) \end{aligned}

(a simplified approximation; the real formula meteorologists use is more complex)

Two separate results, from two separate calculations; let’s see the flow diagram.

Pattern 2 →\rightarrow Group 1: Temperature Conversion

Temperature and Heat Index →\rightarrow Full Program (Group 1)

#include <stdio.h>

int main() {
    float fahrenheit, celsius, humidity, heatIndex;

    /* Group 1: Fahrenheit to Celsius */
    printf("Enter temperature in Fahrenheit: ");
    scanf(" %f", &fahrenheit);
    celsius = (fahrenheit - 32.0f) * 5.0f / 9.0f;
    printf("%.1f F = %.2f C\n", fahrenheit, celsius);
    // ... continued in Group 2

The first complete Input/Process/Output group; reads fahrenheit, computes, prints.

Temperature and Heat Index →\rightarrow Full Program (Group 2)

    // ... continued from Group 1
    /* Group 2: heat index from temperature and humidity */
    printf("Enter relative humidity (%%): ");
    scanf(" %f", &humidity);
    heatIndex = 0.5f * (fahrenheit + 61.0f
                + (fahrenheit - 68.0f) * 1.2f + humidity * 0.094f);
    printf("Heat index: %.1f F\n", heatIndex);
    return 0;
}

The second complete group; reuses fahrenheit, but reads its own input (humidity).

Temperature Converter →\rightarrow a Casting Pitfall

A closer look at the Fahrenheit-to-Celsius conversion from Pattern 2:

#include <stdio.h>

int main() {
    float fahrenheit, celsius;

    printf("Enter temperature in Fahrenheit: ");
    scanf(" %f", &fahrenheit);

    celsius = (fahrenheit - 32.0f) * 5.0f / 9.0f;

    printf("%.1f F = %.2f C\n", fahrenheit, celsius);
    return 0;
}
Sample run
Enter temperature in Fahrenheit: 98.6
98.6 F = 37.00 C

Note the cast-awareness: 5.0f / 9.0f is floating-point division; writing 5 / 9 would give 0; integer division!

Summary

Summary

  • Arithmetic: +, -, *, /, %; integer division truncates; % is integers-only

  • Precedence: same as BEDMAS; parentheses override

  • Constants: #define for preprocessor substitution; const for typed constants; eliminate magic numbers

  • Type casting: cast the operand, not the result, to get floating-point division

  • Increment/decrement: postfix uses-then-changes; prefix changes-then-uses; use compound assignment (+=, -=, …) for clarity

  • Standard library: pre-written, tested tools; include the header, call the function, link (-lm)

  • Chaining: multiple Process/Output blocks in sequence; no new diagram shapes
